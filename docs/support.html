Getting Started

StickyPresenter lives in your menu bar (the 📝 icon). Click it to create sticky notes, open timers, or start the teleprompter. The app has no Dock icon and runs quietly in the background.

Features

  • Floating sticky notes — stay on top of full-screen Keynote, 6 colors, adjustable opacity, font size, and lock.
  • Timers — square countdown widgets you can resize, theme (light / dark), show / hide, align next to the panel, or open in their own window for screen sharing & AirPlay. A chime and a pulsing border signal when time is up.
  • Teleprompter — auto-scrolling script with adjustable speed, font size, and mirror mode.

FAQ

The timer window — can I add it as a source when screen mirroring?
Yes. Use the Window button on a timer row to open it as a real window, which appears in your mirroring / screen-sharing "add window" list.

I hid a timer widget and can't find it.
Hover the timer's row in the panel to see its location (a dashed outline), or press Align to bring it back next to the panel.

Remote Controller (iPhone)

The Remote Controller app runs your timers from your iPhone: start and pause, add or subtract 30 seconds, resize the widget, drag it somewhere else on your Mac's screen, hide it, or start a preset timer. Open it while StickyPresenter is running on a Mac on the same Wi-Fi — it connects on its own, with no account or pairing code.

It can't find my Mac. In order, check:

  • StickyPresenter is running on the Mac — look for the icon in the menu bar. Closing every window does not quit it, but quitting it does stop the remote from finding it.
  • Both devices are on the same Wi-Fi. A guest network, or one device on cellular, will not work.
  • Local Network is allowed on the iPhone — Settings → Privacy & Security → Local Network → Remote Controller.
  • Local Network is allowed on the Mac — System Settings → Privacy & Security → Local Network → StickyPresenter.
  • Turn off any VPN. It commonly hides other devices on the same network.

Can someone else control my timers? On the same local network, yes — there is no pairing code, and only timers can be controlled. See the Remote Controller privacy policy.

한국어

시작하기

StickyPresenter는 메뉴바(📝 아이콘)에서 동작합니다. 아이콘을 눌러 스티키 노트를 만들거나 타이머·텔레프롬프터를 열 수 있습니다. Dock 아이콘 없이 백그라운드에서 조용히 실행됩니다.

주요 기능

  • 플로팅 스티키 노트 — Keynote 전체 화면 위에도 표시, 6가지 색상, 투명도·폰트 크기·잠금 지원.
  • 타이머 — 크기 조절 가능한 정사각형 카운트다운 위젯. 테마(라이트/다크), 표시/감추기, 패널 옆 정렬, 화면 공유·AirPlay용 별도 윈도우로 열기. 종료 시 차임과 테두리 펄스로 알림.
  • 텔레프롬프터 — 자동 스크롤 대본, 속도·폰트 크기 조절, 좌우 반전(미러) 모드.

자주 묻는 질문

화면 미러링에서 타이머를 윈도우로 추가할 수 있나요?
네. 타이머 행의 Window 버튼으로 실제 윈도우로 열면 미러링/화면 공유의 "윈도우 추가" 목록에 표시됩니다.

타이머 위젯을 감췄는데 어디 있는지 모르겠어요.
패널에서 해당 타이머 행에 마우스를 올리면 점선으로 위치를 보여줍니다. 불러오기(Align)를 누르면 패널 옆으로 다시 가져옵니다.

리모컨 앱 (iPhone)

Remote Controller 앱으로 iPhone에서 타이머를 조작합니다 — 시작·일시정지, 30초 더하기/빼기, 위젯 크기 조절, Mac 화면 위에서 위치 옮기기, 감추기, 프리셋 타이머 시작. 같은 Wi-Fi의 Mac에서 StickyPresenter가 실행 중일 때 앱을 열면 계정이나 페어링 코드 없이 알아서 연결됩니다.

Mac을 찾지 못할 때 순서대로 확인하세요.

  • Mac에서 StickyPresenter가 실행 중인지 — 메뉴 막대의 아이콘으로 확인합니다. 창을 모두 닫아도 앱은 남아 있지만, 종료하면 리모컨이 찾지 못합니다.
  • 두 기기가 같은 Wi-Fi인지. 게스트 네트워크이거나 한쪽이 셀룰러면 찾지 못합니다.
  • iPhone의 로컬 네트워크 허용 — 설정 → 개인정보 보호 및 보안 → 로컬 네트워크 → Remote Controller.
  • Mac의 로컬 네트워크 허용 — 시스템 설정 → 개인정보 보호 및 보안 → 로컬 네트워크 → StickyPresenter.
  • VPN을 끄세요. 같은 네트워크의 기기를 못 찾게 하는 흔한 원인입니다.

다른 사람이 제 타이머를 조작할 수도 있나요? 같은 로컬 네트워크라면 가능합니다 — 페어링 코드가 없습니다. 조작 가능한 것은 타이머뿐입니다. 자세한 내용은 Remote Controller 개인정보 처리방침을 참고하세요.
